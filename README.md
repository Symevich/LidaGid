# ЛідаГід — аўдыёгід па горадзе Ліда

🔗 **Жывы сайт:** https://symevich.github.io/LidaGid/

Інтэрактыўны аўдыёгід па славутасцях горада Ліда. Гэта аднастаронкавы сайт (SPA/PWA) на чыстым HTML/CSS/JavaScript, які працуе афлайн і падтрымлівае некалькі моў.

## Магчымасці
- Спіс славутасцяў з фота, апісаннямі і аўдыясуправаджэннем (mp3).
- Міні-квізы да аб'ектаў.
- Карта (Leaflet) і QR-код для падзяліцца спасылкай.
- Праца афлайн (service worker), мовы: беларуская, руская, англійская.

## Тэхналогіі
Чысты HTML/CSS/JS (без фрэймворкаў), Leaflet, PWA.

## Запуск
Гэта статычны сайт — проста адкрый `index.html` або ўключы GitHub Pages.

> Гэта базавая версія. Яе развіццё з функцыяй распазнавання славутасцяў па камеры — у рэпазіторыі [lidalens](https://github.com/Symevich/lidalens).
